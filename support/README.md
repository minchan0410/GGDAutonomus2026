# Tele Operation by keyboard

| key | action |
| :--- | :--- |
| `key UP` | move forward |
| `key DOWN` | move backward |
| `q` | turn left |
| `w` | turn right |

<br>

- Because of PID parameters, the command topics should not change rapidly **(overshoot)**. 
<br>
Setting the rising and falling steps is important.
